
# Выбор локации для скважины

## Задача
Даны данные по трём регионам (качество нефти и объём запасов).  
Цель — определить регион с максимальной прибылью и минимальным риском убытков с помощью ML и bootstrap-оценки.

---
## Данные
- 3 региона, по 100 000 наблюдений на каждый  
- 3 признака + целевая переменная (объём запасов)

---
## Краткий итог
- **Лучший регион:** geo_data_2 (третий регион)
- **Средняя выручка:** 564 млн руб.  
- **Риск убытков:** 2%  
- **Модель:** Linear Regression  
- **RMSE:** 38 тыс. баррелей  

## Подход

- Проведён EDA и проверка качества данных;
- Обнаружена аномалия с целевым признаком и утечка данных во 2 регионе → исключён из анализа;  
- Выполнен feature engineering: добавлен бинарный признак для первого региона и преобразованны признаки для третьего; 
- Обучена модель линейной регрессии (по условиям задачи);  
- Проведена оценка прибыли и рисков с помощью bootstrap.  

## Результаты

**Регион 1:**
- Средняя прибыль: 481 млн руб.  
- Риск убытков: 2.8%
- RMSE: 37.1 тыс. бар

**Регион 3:**
- Средняя прибыль: 563 млн руб.  
- Риск убытков: 2%
- RMSE: 38.2 тыс. бар

**Выбран Регион 3 как оптимальный вариант**

---

## Ключевые моменты

- Утечку данных во втором регионе невозможно обработать: на 100 тысяч строк всего 12 уникальных значений объёма + полная линейная связь с f2 - утечка данных;
- С техникой бутстреп воссоздали ситуацию выбора скважин: из 500 случайных скважин тестовой выборки, выбрали 200 лучших по мнению модели и по истинным значениям рассчитали прибыль и риск убытков (отрицательная прибыль), провели тест для тысячи подвыборок - посчитали среднюю прибыль и риски;
- Feature engineering существенно повлиял на результаты метрик и тестов: снижение риска с 12% до 2% для третьего региона, с 5 до 2.5% для первого. Существенно увеличилась средняя прибыль;
